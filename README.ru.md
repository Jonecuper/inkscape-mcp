# inkscape-mcp — навык для Claude Code

🌐 [English](README.md) · **Русский**

[Навык](https://code.claude.com/docs/en/skills) для [Claude Code](https://claude.com/claude-code)
по работе с [inkscape-mcp](https://github.com/sandraschi/inkscape-mcp) — MCP-сервером, который
позволяет AI-агентам создавать, править, анимировать и экспортировать векторную SVG-графику
через Inkscape.

Навык упаковывает всё, что нужно агенту для продуктивной работы с сервером:

- **Идемпотентный установщик** (`scripts/setup.ps1`) — клон → проверка окружения → установка →
  `claude mcp add` → healthcheck. Можно перезапускать сколько угодно; им же удобно переносить
  настройку на другую Windows-машину.
- **Рабочие скрипты** (`scripts/`) — переиспользуемый инструментарий «растер → чистый вектор»,
  наработанный в реальной сессии ремастера логотипа: `font2svg.py` (контуры глифов напрямую из
  TTF через fontTools — без реестра шрифтов Windows), `fitgeom3.py` (превращает пиксельный
  трейс надписей в минимум примитивов L/A/C: конкуренция покрытий прямая/дуга + привязка к
  осям), `smoothmin.py` (рецепт сглаживания/минимизации через vtracer), `build_final.py`
  (эталон доводки ручной векторизации: скругление углов полигонов дугами, явная капсула
  дефиса, полный pen-state парсер относительных субпутей, разборка на глифы и раскладка по
  эталонным bbox), `setup.ps1` (идемпотентный установщик).
- **Проверенный в бою гид** (`SKILL.md`) — шаги установки, подводные камни найденные на практике
  (cmd «съедает» бэклэши в путях из Git-Bash, долгий первый `uv sync`, необходимость перезапуска
  сессии для появления MCP-инструментов), рецепты цикла «нарисовал → отрендерил → посмотрел» и
  прямой stdio-тест на случай, когда инструменты ещё не подгружены в текущей сессии.
- **Аудит честности** инструментов сервера — что реально работает, а что молча имитирует успех
  (проверено end-to-end):

  | Инструмент / операция | Вердикт |
  |---|---|
  | `create_object`, `export_preview`, `inkscape_file convert/info/validate`, `generate_heraldry`, слои, SMIL-анимации | ✅ работает |
  | `trace_image` | ❌ возвращает `success: true`, не создавая файл (дёргает несуществующее действие Inkscape) |
  | `generate_barcode_qr` | ❌ рисует данные моноширинным текстом вместо матрицы QR |
  | `create_object` (повторные вызовы) | ⚠️ каждый вызов перезаписывает документ целиком |

## Установка

Клонируйте репозиторий прямо в папку навыков Claude Code:

```bash
git clone https://github.com/Jonecuper/inkscape-mcp ~/.claude/skills/inkscape-mcp
```

Перезапустите Claude Code. Навык подхватывается автоматически, когда речь заходит о векторной
графике, либо вызывается по имени.

Чтобы подключить сам MCP-сервер на машине с Windows 10/11 (нужны Inkscape 1.2+ и `uv`):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ~/.claude/skills/inkscape-mcp/scripts/setup.ps1 -TargetDir C:\dev\tools\inkscape-mcp
```

…или просто попросите Claude: *«настрой inkscape-mcp на этой машине»* — навык проведёт его
по тому же скрипту.

## Примечания

- `scripts/setup.ps1` обязан оставаться в **UTF-8 с BOM** — Windows PowerShell 5.1 иначе ломает
  кириллические комментарии при парсинге. Правило в `.gitattributes` это защищает.
- Навык написан для Claude Code, но `SKILL.md` — обычный Markdown: заметки и аудит инструментов
  будут полезны любому, кто автоматизирует работу с inkscape-mcp.

Вышестоящий проект: https://github.com/sandraschi/inkscape-mcp (сервер в тестах: v3.4.5, Inkscape 1.4.4, 2026-11).
